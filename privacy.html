Privacy policy

Last updated 23/10/2026

Dashboard is a private tool used by one person. It is not available to anyone else.

Google data it uses

  • Google Calendar (read only): event titles, times and locations for this week and next, from calendars the owner chooses.
  • Google Tasks: the items on one shopping list the owner chooses. The tool can add items and mark them complete. During setup it reads the names of the owner's task lists so one can be chosen.

How the data is handled

  • Data goes straight from Google to the PC and is shown on a page that only that PC can open.
  • Calendar events and shopping items are held in memory while the program runs and are not saved to disk.
  • The Google sign-in is stored in Windows Credential Manager on that PC.
  • Google data is not sold, shared or sent to anyone else, is not used for advertising and is not used to train AI models.

Dashboard's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Use the support email shown on this app's Google sign-in screen.
